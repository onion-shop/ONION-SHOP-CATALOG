Редактор товаров ONION SHOP

Правки сильнее текста поста. Удалите правку — вернётся то, что написано в канале.

Вход

Один раз вставьте токен GitHub (fine-grained, репозиторий ONION-SHOP-CATALOG, права Contents: Read and write и Actions: Read and write). Он хранится только в этом браузере.

Как получить токен (один раз)
  1. github.com → фото профиля → Settings → внизу слева Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token. Name: editor, срок 1 год.
  3. Only select repositories → ONION-SHOP-CATALOG.
  4. Permissions: Contents — Read and write и Actions — Read and write.
  5. Generate token, скопируйте текст с github_pat_ и вставьте выше.
Вставляйте только настоящие отзывы из канала отзывов.

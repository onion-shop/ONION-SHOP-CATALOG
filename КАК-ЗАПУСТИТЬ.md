# Магазин ONION SHOP: как запустить

Сайт работает бесплатно на GitHub Pages. Товары берутся из Telegram-канала
@ONION_SHOP_OFFICIAL автоматически, раз в час. Новый товар просто публикуете
в канале, как раньше, и он сам появляется на сайте.

## Один раз: выложить сайт

1. На GitHub нажмите **New repository**. Название: `shop`. Тип: **Public**. Создайте репозиторий.
2. Распакуйте архив и перетащите в окно **uploading an existing file** всё содержимое папки:
   `index.html`, `manifest.webmanifest` и папки `assets`, `data`, `img`, `scripts`. Нажмите **Commit changes**.
3. Файл автообновления (папку, которая начинается с точки, GitHub при перетаскивании не берёт):
   **Add file → Create new file**, в имени файла наберите `.github/workflows/sync.yml`,
   вставьте текст из файла `sync.yml` из архива и нажмите **Commit changes**.
4. **Settings → Pages → Source:** выберите **GitHub Actions**.
5. **Actions → «Каталог из Telegram» → Run workflow.** Через 1–2 минуты сайт откроется по адресу
   `https://onion-shop.github.io/shop/`.

## Как пост становится товаром

Пишите посты в том же виде, что и сейчас:

```
Свитер Hollister
———
•состояние: новое с биркой
•цена: 3490                ← зачеркните старую цену, и сайт покажет скидку
•цвета: белый, серый, розовый
•размер: S / M / L

❗️ товар оформляется по предзаказу   ← без этой строки товар считается «в наличии»
```

- Обязательна строка **цена** с числом. Без неё пост на сайт не попадает (поздравления, новости и т. п.).
- Допишете в пост **«товар продан»**, и он исчезнет с сайта при следующем обновлении.
- Удалите пост, и товар тоже исчезнет.
- Второй альбом с фото **без текста**, отправленный в течение 30 минут после поста, добавится к фото этого товара.
- Размеры пишите через `/` (S / M / L). Для обуви можно диапазоном: `41-45`.

## Если что-то пошло не так

- **Actions** показывает каждый запуск. Красный крестик означает, что обновление не прошло, а сайт остался прежним.
- Если в канале вдруг не найдётся ни одного товара, каталог не стирается, а остаётся прежним.
- Обновить вручную: Actions → «Каталог из Telegram» → **Run workflow**.

## Кабинет, токены, рулетка и заказы в Telegram

Их включает Google Таблица, настройка займёт около 15 минут. Пошагово — в файле **«Google-Таблица-и-бот.md»**.
Пока она не сделана, сайт работает без кабинета: корзина, избранное и «Мои заказы» хранятся в браузере
покупателя, а текст заказа он отправляет менеджеру сам.

## Что в архиве

| Файл | Зачем |
|---|---|
| `index.html`, `assets/`, `data/`, `img/`, `manifest.webmanifest` | сайт |
| `scripts/sync_catalog.py`, `sync.yml` | автообновление каталога из канала |
| `Code.gs` | код для Google Таблицы (кабинет, токены, заказы, бот) |
| `assets/config.js` | сюда вставляется ссылка на Google Таблицу |
| `assets/core.js` | правила токенов, уровней и рулетки (общие для сайта и таблицы) |
